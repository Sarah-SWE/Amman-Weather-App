# Amman Weather App

Amman Weather App is a responsive front-end weather web application built with React. It displays real-time weather conditions for Amman, Jordan, with dynamic bilingual support (English & Arabic) and automatic layout direction switching (`LTR` / `RTL`).

## Features
- View real-time temperature in Celsius alongside daily minimum and maximum temperatures
- Display live weather condition descriptions and dynamic weather icons
- Bilingual interface supporting English and Arabic translations (`react-i18next`)
- Automatic layout direction switching (`RTL` / `LTR`) and localized date/time formatting (`Moment.js`)
- Clean, responsive card-based UI styled with Material UI and custom CSS

## Tech Stack
**Frontend:** React, Material UI (MUI), Axios, i18next, Moment.js, CSS3
**API:** OpenWeatherMap API
